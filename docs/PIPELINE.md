# 《老周家》生产流水线 PIPELINE · 九段五关卡

> 半自动化标准流程：**AI 干活，人守关卡**。每一集都按此走，不重新发明格式。
> 创意线文档（点子/剧本/分镜）放 `../character-assets/scripts/`；生产线文档（提示词包/clips/发布包）放本仓 `episodes/EPxx-主题/`。
> 创建：2026-08-26｜依据：EP01 实战复盘 + 短视频剧本方法论调研

## 〇、总览图

```
S0 点子卡(人)
 └→ S1 完整剧本(AI) ─【G1 人审·剧本定稿】→ S2 分镜表(AI) ─【G2 人审·镜头方案】
     └→ S3 提示词包(AI) → S4 资产生图(NB2·0点) → S5 视频生成(MCP七步)
         └─【G3 人眼逐镜验收】→ S6 ffmpeg粗剪 ─【G4 整片观感】
             └→ S7 剪映精修(人) ─【G5 发布前检查】
                 └→ S8 发布素材包(AI) → S9 发布+数据复盘(人↔AI) ↩ 流失段反哺下一集剧本
```

## 一、分段定义

| 段 | 名称 | 执行者 | 产出物 | 要点 |
|----|------|--------|--------|------|
| S0 | 点子卡 | 人 | 选题池加一行 | 一句话+冲突内核即可；豆包等粗稿只当原料，必须老周家化改造（人设映射、口头禅、调性校准） |
| S1 | 完整剧本 | AI | `scripts/EPxx-标题-剧本.md` | 用模板①。硬性自检：0–3s 出事出声／每 15s 一个节拍／中段(40–60%处)大反转／结尾互动钩子／口头禅全片 ≤2 处 |
| **G1** | **剧本关卡** | **人** | 定稿版号 +1 | 台词逐句过，语气不像人就当场改；不过不进下一段 |
| S2 | 分镜表 | AI | `scripts/EPxx-标题-分镜.md` | 用模板②。**单镜 ≤10s（Omni Flash 上限，硬约束）**、一镜一事、同框正脸 ≤2、屏幕全 UI 后期；附预算表 = Σ(镜时长×单价) |
| **G2** | **分镜关卡** | **人** | — | 挂图方案、笑点递进确认后冻结 |
| S3 | 提示词包 | AI | `episodes/EPxx/prompts/SHxx.md` | 用模板③。STYLE_BIBLE 锁定句原样复制禁改；提示词**不写台词**只写口型动作 |
| S4 | 资产生图 | AI(MCP) | 场景图→`assets/scenes/`；道具图→资产库 `scenes/*/ _epxx/` | NB2 0 点。先查 `scenes/manifest.json` 与 SCENE_LOCK 复用，缺的才新做 |
| S5 | 视频生成 | AI(MCP) | `clips/SHxx_v版本.mp4` | flow-video-generation skill 七步循环；Omni Flash 8s=12点/6s=10点；输出数量 x1；提交即验证防白扣点 |
| **G3** | **逐镜验收** | **人** | 验收记录进 notes.md | AI 只验技术参数（时长/分辨率/mediaId）；表情、手指、像不像必须人眼；重 roll 同镜 ≤2 |
| S6 | 粗剪 | AI | `clips/demo-EPxx-v0.mp4` | workflow.md 附录B：编码一致 concat -c copy 无损；不一致先修差异再重编 |
| **G4** | **观感确认** | **人** | — | 节奏与笑点停顿是否成立 |
| S7 | 精修 | 人(剪映) | `EPxx-主题_日期_final.mp4` | voice.md 固定音色配音＋大字幕＋片尾字幕＋「AI 生成」标注。**此环节无 API，永久人工** |
| **G5** | **发布前检查** | **人** | — | 合规（AI 标注、孩子镜头规则）、封面、首评准备 |
| S8 | 发布素材包 | AI | `episodes/EPxx/release.md` | 用模板④：标题候选×3／封面文案／话题标签／置顶评论／发布时间建议 |
| S9 | 发布+复盘 | 人↔AI | 完播率曲线截图 → AI 标注流失时间点 → 反推剧本段落 | 结论回写 notes.md 与选题池，闭环到 S1 |

## 二、成本与记账

- 生图 NB2 = 0 点；视频 Omni Flash 实测 8s=12 点、6s=10 点（2026-08-24 实测）；**10s 单价未实测**，首次使用以 credits API 实扣为准后回填本表
- **单镜时长硬上限 10 秒**（模型能力边界），拆镜时在 ≤10s 内按节奏需要定长短，不为凑上限而拉长
- 每笔消耗当天记 `ledger/credits.md`
- 立项预算公式：`Σ(各镜时长单价) × 重roll系数 1.3`，写入分镜表预算栏

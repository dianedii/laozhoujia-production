# Voice · 声音规范

> 决策记录：2026-08-22 定稿——**台词 100% 剪映后期配音（方案 A）**。视频生成时不带台词，只保留画面+环境音。理由：跨集音色绝对一致 > 口型完美同步；抖音家庭剧受众看大字幕，不看嘴。

## 一、视频生成侧（提示词怎么写）

- 提示词中**不写任何台词内容**
- 人物说话时写口型动作：`talking with expressive mouth movement` / `mouth open mid-sentence`
- 音频段只描述环境音：
  ```
  AUDIO: kitchen ambience, running water sound, faint TV noise from living room, no dialogue, no background music
  ```

## 三、配音卡说明

每个 `SHxx.md` 文件末尾有「配音卡」，格式：

```
【配音卡】
角色: 周磊
台词: 「今晚洗碗，包在我身上。」
语气: 叉腰拍胸的自信，尾音上扬
时长参考: 约3秒（对应 SH01 第2-5秒）
```

剪辑时按「时长参考」对位放置语音，字幕同步生成。

## 四、其他声音元素

| 元素 | 来源 | 规范 |
|------|------|------|
| 环境音/音效 | 视频原生生成 | 保留 |
| BGM | 剪映曲库固定 3 首轮换 | 音量 ≤ 人声 -12dB |
| 片尾金句字幕音 | 剪映统一"叮"音效 | 每集同一款 |

## 五、待验证项（SH01 对照实验）

EP01 的 SH01 会额外用 Omni Flash 出一条**带原生中文对白**的对照版（+25 点），对比：
1. 中文发音自然度
2. 音色可用度
3. 与剪映配音的整体效果差

结论记入 `episodes/EP01-xiwan/notes.md`；若原生对白质量高且稳定，再评估是否部分镜头改用方案 B（原生+音频参考锚定）。
